# 审图相关想法

先记录观察，不代表已经确定审图规则，也暂不实现。

- 技术要求等连续编号如果出现跳号，例如从 `5` 跳到 `7`，以后可以作为审图关注点。需要先分清是源图确实缺号，还是抽取遗漏、图纸认错。
  - 已确认实例：`5TBC.384.A110050.1_1`（上节油箱）的源图技术要求确实从 `5` 跳到 `7`；用户已于 2026-08-26 打开源图目视确认，不是抽取遗漏。
  - 对照：`5TBC.384.A110050.2_1`（下节油箱）存在第 `6` 条，且已正常抽取（句柄 `33EE`）。
- 普通文字、线、块参照等实体如果位于最外层图框外，或者与图框边界相交，以后可以作为审图关注点。哪些情况正常、哪些算问题，后续结合实际图纸再总结。
