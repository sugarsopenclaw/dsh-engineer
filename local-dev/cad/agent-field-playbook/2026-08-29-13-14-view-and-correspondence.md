# 13/14：视图 scope 与表达对应踩坑

## 先被实图推翻的假设

- 直接把相距很近的连通分量聚类，会被纸张外框/标题骨架这个“覆盖全图的连通分量”串成一个大区。
- 大区只要包含技术要求，就会被错误标成“整张图都是文档区”。
- 三五条边的小孔或符号若一律叫视图，重复几何和投影关系会产生大量看似合理的噪声。
- `长得一样` 和 `投影坐标对齐` 都不足以证明两个 scope 是同一业务对象。

## 最终规则

1. 先识别纸张尺度结构并单独成区，再聚类局部组件；已知标题栏/BOM/技术要求可在没有结构线时独立成文档区。
2. 小型闭合几何照常保留，但低于边数/图纸尺度门槛时叫 `local_geometry_region`，不送进跨视图对应。
3. 视图名称只接受原图文字；几何无名就是候选。
4. 重复拓扑输出 `same_type_candidate_only`；强投影输出 `same_object_possible / possible_not_proven`；两者均不得自动合并对象。
5. 投影匹配必须保存两侧 feature station、vertex ID、覆盖率、容差、中心和范围残差，不能只留一个分数。

## 可重放证据

`12-planar-topology-kernel/replay-saved-instance-facts.ps1` 现可把保存的 11 事实连续重放到 12/13/14，并生成每图详细 JSON 和总摘要。七图当前为 125 个 scope、76 个视图候选、514 个区域对、19 条保留关系；数字证明预算与契约可运行，不代替逐项业务标注。

## 仍未证明

- 旋转图框、斜投影、跨图框视图和没有 PCCAD 标识的文档区。
- 视觉同形但因交点切分不同而拓扑签名不同的完整召回率。
- 强投影候选与沈变真实“同一构件”的人工真值精度。
