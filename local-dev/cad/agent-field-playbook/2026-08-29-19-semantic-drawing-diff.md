# 19 现场记录：跨版本差分

## 最容易踩的坑

- 直接按 handle 做集合差：重存、复制或重建实体会把技术变化和数据库身份变化混在一起。
- 先匹配再验图纸身份：拿错图或页码后会产生整图“删除 + 新增”的灾难性假阳性。
- 用任意仿射配准：会把真实缩放、旋转或局部移动一起消掉。
- 为了产出唯一结果强行拆平局：重复孔、重复线和阵列中等距候选必须保留多解。
- 在输入/候选被截断时推断删除：没处理到不等于不存在。

## 最终工作法

1. 每次抽取先冻结 04/05/08/11/13/16/17/18 的语义快照；保留作者字段、稳定键、fallback 签名、坐标、关系、源 handle 和上游状态。
2. 先比较图样代号与页码；无可靠身份就停止批量差分。
3. 用唯一稳定且几何未变的锚点只估计整图平移；支持不足就保留坐标歧义。
4. 唯一稳定键优先；handle 变化时才用结构签名和对齐后空间近接。平局不选边。
5. 将几何、局部移动、语义、样式和关联变化分别输出，再生成尺寸同步候选、issue 生命周期和差异区域。
6. 先跑同一快照自差分；变化、新增、删除或多解不为零时，不进入真实版本比较。

离线入口是 `compare-semantic-drawing-snapshots.ps1`。七图当前只有单版保存事实，所以只能验证自差分不变量；真实跨版精度必须等待同图号同页码的修订对。
