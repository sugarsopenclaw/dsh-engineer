# 12 · 切节点平面拓扑内核

`PlanarTopologyAnalyzer.cs` 只消费 11 的世界坐标曲线 occurrence，不依赖 Teigha/BricsCAD。它把“端点差一点、线在中途相交、共线重叠、一个 definition 被多次插入”统一转成可追溯的平面 arrangement 和 DCEL；所有吸附、量化和切分都只发生在派生结果中，源 DWG 与 11 路径不变。

## 处理流水线

1. **参与范围**：默认排除 08 标注、中心参考、双点划参考和剖面填充角色；不可见 occurrence 及超过 Z 平面容差的曲线不进入结构拓扑，但保留诊断。配置可重新纳入任一角色。
2. **非破坏吸附计划**：端点用空间桶 + 并查集聚类，代表点按质心距离、总距离和稳定 ID 确定；端点到线段内部可生成投影计划。同一 occurrence 的不同坐标不得仅因容差合并，近似曲线内部采样点也不作为端点吸附候选。若吸附会折叠源边，则拒绝该边的吸附动作并报告冲突。
3. **全交点切分**：层级空间网格枚举包围盒真正相交的候选对，处理真交点、端点接触及共线重叠区间；每条源线段收集参数后有序切分。
4. **固定网格规范化**：派生点量化到整数网格；同一无向片段合并为一条 edge，但保留全部 occurrence、源句柄、源线段序号、参数区间、方向、角色和几何质量支持。
5. **图与面**：输出点度数、端点、分支和连通分量；每条无向边生成 twin halfedge，按顶点极角构造 `next` 并遍历环。正面积环形成有界面，直接包含的子环成为孔洞并从净面积扣除。

## 正常状态与校验

`computed / ambiguous / unsupported_partial` 都是正常数据状态，不以异常掩盖图纸问题。输出至少校验：

- `halfedge_count = 2 × edge_count`；
- twin 为对合；
- next 为全 halfedge 的置换；
- 每个 halfedge 恰好进入一个环；
- `V - E + (bounded faces + 1) = 1 + connected components`；
- 严格 Euler 差额等于显式输出的未成面环秩，区分“已解释的退化/零面积环”与拓扑账目丢失。

工程图可能存在零长度源段、量化塌缩、共线退化环或组合环秩不能形成正面积面的情况。12 同时输出环总数、正/负面积环、退化环、组合环秩和未成面环秩；不会为了让 Euler 等式好看而伪造面。

## 规模保护与性能证据

默认最多接收 250,000 个归一化线段和 12,000,000 个实际包围盒候选对。长线先在细网格失败时逐级进入更粗网格，而不是直接与全图 O(N) 比较；阶段耗时分别记录为输入构造、吸附、交点切分、片段 arrangement、连通分量、DCEL/面。

合成回归覆盖方形面积、十字中途交点、共线重叠多源支持、近 T 端点投影、嵌套环孔洞、角色排除、间距小于吸附容差的 100 个近似曲线内部采样段不被折叠，以及会折叠人工短边的传递吸附被拒绝且源边仍参与切节点。

真实七图回归先明确暴露了近似曲线内部采样点误入端点吸附和空间索引尺度退化；第一轮修复后，`384.2` 从约 20 秒降到 2.4 秒且错误折叠归零，`457` 从 133 秒降到 21 秒。最终版“折叠源边拒绝”和“长线分层粗网格”已把七张保存的 11 世界坐标事实全部重放：无图触发候选预算，`384.1` 的 Core 12 从约 148 秒降到约 33 秒，两个 709 大图分别约 38 秒和 27 秒；六张图的严格 Euler 差额均被 `unresolved_cycle_count` 逐项完全解释，最小图为全 `computed`。这证明的是最新版 Core 对真实事实的回归，不替代 THCAD 实体读取。

连续宿主回归在处理第五张 `709.1_1` 的实体反射阶段触发 THCAD 原生 `HyperLinkCollection` 终结器崩溃；Adapter 现已显式跳过该属性、按声明类型排除原生包装器，并释放广义返回类型中实际出现的临时包装器。修复后曾在新的 THCAD 进程中旁读最小图，逐实体失败为 0，12–14 全链产物完成且宿主仍响应；15/16/17/18/19 加入后已完成离线编译和保存事实回归，但尚未在当前已加载旧程序集的 THCAD 中热更新。连续多图和此前崩溃点的大图仍待复验。因此当前证据应表述为“Core 合成与保存事实七图回归完成、旧版 Adapter 的 THCAD 新进程单图通过”，不能写成最新版最终端到端七图全绿。
