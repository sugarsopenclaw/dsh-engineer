# 06 · 图层分析

核心实现只有一个源文件：`CadLayerAnalyzer.cs`。

它把 CAD 图层定义与全量实体上的 `layer` 关联起来，回答“有哪些图层、哪些被使用、每层有什么实体、当前图层状态会压住多少模型空间实体”。Core 不引用 THCAD、Teigha、BricsCAD、COM、文件系统或 JSON，也不会修改图纸。

## 分析内容

- 图层名称、句柄、开关、冻结、锁定、颜色和线型；
- 每层的模型空间实体数、块定义实体数、实体类型分布和块参照目标；
- 已定义但未使用的图层、实体引用的未定义图层、没有图层的实体；
- 实体自身 `visible` 与图层开关/冻结分开统计；
- `FindLayer(name)` 和 `FindEntityHandles(layer, ownerScope)` 可直接作为以后函数工具的基础。

THCAD 整图抽取会生成：

- `layer-analysis.json`：机器可查询的完整汇总与诊断；
- `layer-analysis.md`：面向人和 LLM 的图层清单、数量、主要实体类型及当前状态。

## 为什么区分模型空间和块定义

全量实体里既有当前模型空间中的实体，也有块库中的定义实体。块定义的一条 Line 可能被多个块参照重复显示，也可能根本没有插入；因此不能把数据库里的块定义实体数直接当作当前画面对象数。

显示/隐藏还要注意：

- 普通模型空间实体受自身图层控制；
- 块参照本身也有图层，关闭它的插入图层可以隐藏整个参照；
- 块定义内部的非 0 层实体仍受各自图层控制；
- 块内 0 层内容通常随块参照的插入层表现；
- 实体 `visible=true` 不代表最终可见，所在图层关闭或冻结时仍不会显示。

## 七图验证

- 每张图定义 27–65 个图层，七图并集 95 个名称，其中 22 个七图共有；
- 共核对 91,605 个实体：模型空间 12,165，块定义 79,440；
- 所有实体都有图层，且全部能对应到图层定义；
- 每张图都有且只有 `消隐层` 处于关闭状态，合计压住 162 个模型空间实体；
- 七图没有冻结或锁定图层，也没有实体自身 `visible=false`；
- 这批数据恰好说明“实体属性可见”和“图层最终显示状态”不能混为一谈。

## 当前边界

- 只分析当前抽取到的数据库实体，不展开计算每个嵌套块的最终渲染实例数；
- 块参照的 AttributeReference 目前作为块属性嵌套数据，不单独计一条实体；
- 当前只读分析；真正切换 CAD 图层开关需要以后单独做有状态的 THCAD Adapter 工具。
