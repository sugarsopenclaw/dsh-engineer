# 13 · 工程视图与局部区域

13 把 11 的统一世界坐标和 12 的平面拓扑整理成可供后续算法使用的局部 `scope`。它回答“哪些几何属于同一个空间区域”，不回答“这一定是哪个零件的主视图”。

## 输入与输出

- 输入：11 的 occurrence、12 的点/边/面/连通分量，可选的 02 图框、图面文字，以及 04/05 等已经确认的文档区包围盒；
- 输出：区域边界、局部正交坐标架、尺度、拓扑和 occurrence 证据链、附近原文标签及已知文档区关联；
- 区域种类：工程视图候选、剖视/详图/向视图候选、未提升成视图的小型局部几何、文档区、纸张结构和稀疏辅助几何区；
- 状态：几何只能产生候选；`剖视`、`详图` 等名称只有原图文字支持时才输出。

## 确定性边界

1. 默认只用模型空间中可见、结构性的曲线，排除 08 标注、07 中心参考、09 双点划参考和剖面填充，避免跨视图尺寸线把多个视图粘成一块。
2. 先以 12 的连通分量为原子，再用自适应间距合并邻近原子；间距由图框对角线和原子尺度共同约束，也可由调用者显式给定。
3. 02 的图框边句柄不参加区域聚类；04/05 等已知文档区优先于“看起来像视图”的几何判断。
4. 横跨大部分图框宽高的连通分量单列为纸张结构，不能作为桥把所有局部组件粘成一块；小于图纸尺度阈值的闭合细节仍保留为局部几何，但不送入 14 冒充独立视图。
5. 每个区域保留 component、edge、vertex、occurrence、文字和文档区 ID，便于 Agent 回到原始证据，不只拿一个裁剪框。
6. 局部坐标架由边长加权的双角统计确定，旋转 180° 不改变主轴；`orthogonal_edge_length_coverage` 只描述画法几何的正交程度，不证明业务身份。
