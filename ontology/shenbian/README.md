# 沈变图纸审查 Ontology

`v1/ontology.yaml` 是早期探索得到的 Object / Link / Action 候选清单，目前只作为术语草案。

正式对象和动作将从 Harness 的图纸净化、铁芯叠片校验工具契约中逐项收敛。该文件不是当前实现主线，也不要求将本地 DWG 图元预先上传或写入 FastAPI。

`v2/business-requirements.yaml` 是客户需求发现阶段的业务 Ontology：以原始需求证据为根，维护需求拆分、复用、适用范围、候选验收条件和待确认项；实例由 Data Layer 的 `shenbian.client_requirements.curated.v1` 提供。
