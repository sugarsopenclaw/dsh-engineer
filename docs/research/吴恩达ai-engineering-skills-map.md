**Andrew Ng 这篇帖子详细展开了他提出的 AI Engineering Skills Map 中的最高层级技能之一：构建与部署 AI 应用。**

他将其拆解为六个具体能力：

### 1. LLM 基础（LLM foundations）
理解 tokenization、生成机制、上下文窗口权衡、缓存命中、知识截止日期、采样参数、工具调用、多模态模型，以及何时做 fine-tune 或自托管模型。这能让你判断模型什么时候可靠、什么时候会失败。

### 2. 用数据 grounding 模型（Grounding models with data）
不只是基础 RAG。要决定什么内容直接放进 prompt、什么内容让模型通过工具按需检索；选择合适的数据表示方式（向量索引、知识图谱、结构化数据上的语义层）；把文档（文本、PDF、HTML、图片）转成 LLM 可用的输入，并建立保持数据干净和新鲜的流水线。

### 3. 构建 Agentic 系统（Building agentic systems）
从预定义的工作流，到让 LLM 反复自主决定下一步的 agent harness。需要选择架构（哪些步骤串联、哪些并行、什么时候用代码、什么时候用 LLM），设计工具（包括 MCP、CLI、沙箱执行环境）、记忆架构、长会话上下文管理，以及何时需要多智能体编排。还要把原型做成可靠、安全的生产级 agent，包括 guardrails、对抗输入处理和风险治理。

### 4. 以评估驱动开发（Evaluation-driven development）
Ng 认为这是区分普通和优秀 AI 工程师最重要的能力。通过系统的 evals / error analysis 循环，反复把精力集中在更可能有效的方向上。需要会做探索性分析、结合产品和业务洞察决定衡量什么，并理解确定性评估、LLM-as-a-judge、人工介入等不同评估方式，以及如何持续改进评估本身。

### 5. 生产环境运维（Operating in production）
AI 系统的不可预测性、成本和延迟都与传统软件不同。需要建立可观测性、检测漂移、快速响应模型失效和安全事件（如提示注入），用更偏统计的方式做回归测试和 CI/CD，并根据风险校准测试力度。还要会组合模型选择、蒸馏、微调、简化 agent 工作流等方法来优化成本和延迟。

### 6. 机器学习基础（Machine learning foundations）
现代 LLM 建立在监督学习和强化学习之上。优秀的 LLM 工程师通常对机器学习和深度学习有一定深度理解。很多应用仍然需要自己训练或使用经典 ML 模型，因此需要掌握常见模型及其在准确率、训练/推理速度上的权衡，以及 bias/variance、error analysis、数据工程这些核心思维框架。

**核心观点**：AI 应用与传统软件最大的区别在于输出的不确定性更高。因此构建过程必然更迭代——你先做出一部分，观察结果，再根据中间结果决定下一步。真正的能力是学会在不确定中做出高质量的下一步决策。
