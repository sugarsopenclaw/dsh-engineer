## 每条图元留下什么

`decode_status` 为 `full` 或 `proxy`。典型字段：

- `handle` / `runtime_class` / `managed_type` / `dxf_name`
- `layer` / 颜色 / 线型 / 可见性
- `owner_scope`（`model_space` 或 `block_definition`）、所属块名
- `geometry`（线起终点、圆半径、多段线顶点、块插入点/旋转/缩放等）
- `bbox`、`text`、块属性、`xdata`
- proxy 另有 `original_class_name`、`original_dxf_name`、厂商说明

每张图目录内文件：

| 文件 | 内容 |
| --- | --- |
| `extraction-report.json` | 数量、类型统计、哈希、耗时 |
| `entities.jsonl` | 全部图元，一行一条 |
| `proxies.jsonl` | 其中 proxy 子集 |
| `tables.json` | 图层、线型、文字样式、标注样式、RegApp、布局、块清单 |
| `dictionaries.jsonl` | 命名对象字典 / XRecord |
| `drawing.json` | 图纸元数据 + 块清单 |
| `errors.jsonl` | 失败记录（本次全空） |

## 和晓量 DXF 语料的交叉

`cadkernel` 语料里三张图的源哈希与本次一致（`5TBC.384.1` / `426` / `709.1`）。当时 AutoCAD SaveAs DXF 得到的 proxy 数是 110 / 75 / 64，与本次 `AcDbZombieEntity` 计数相同。图元总数略少（本次 25535 / 26041 / 15420，对 DXF 25929 / 26219 / 15454），差在 DXF 展开 ATTRIB 等表示差异，不是漏扫 ModelSpace。
