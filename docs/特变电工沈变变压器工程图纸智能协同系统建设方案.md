# 特变电工沈变变压器工程图纸智能协同系统建设方案

> 建议稿 · V1.0 · 2026 年 8 月

## 一、项目定位

本项目面向特变电工沈变设计、校核、审查、审定及生产协同人员，建设一套部署于企业内网的变压器工程图纸智能协同系统。系统与现有天河 CAD/PCCAD、Creo 及后续具备条件的业务系统协同工作，贯通图纸读取、工程对象理解、规则校验、受控操作、结果复核和过程留痕。

首期聚焦两项核心需求：

1. **生产用 DXF 图纸净化**：在 DWG 工作副本中完成生产对象识别、非生产信息清理和制造几何保护，校验通过后自动导出生产设备可用的 DXF。
2. **铁芯叠片一致性校验**：根据铁芯参数明细重建预期叠片结构，与总图及叠片图中的实际轮廓、孔位、尺寸和级次关系进行核验，形成可定位、可解释、可追溯的校审结果。

项目建设将同步沉淀图纸数字底座、变压器工程知识底座和智能体能力底座，为后续尺寸校审、BOM 一致性、跨图接口校验、版本差异分析、受控改图及 Creo 三维协同提供共用能力。

## 二、总体产品形态

系统采用 C/S 架构和内网私有化部署，形成“一套系统、两个工作入口、三项共性底座、两个首期应用”。

### 2.1 两个工作入口

**智能工作台**采用 DeepSeek Harness Web 形态，配套运行在设计人员工作站的 Agent 执行环境，面向设计、校核、审查、审定和标准化人员提供任务对话、智能问答、规则知识、问题复核和结果说明。用户可围绕天河 CAD 当前图纸直接发起工作，Agent 按任务需要调用本地 CAD 能力和企业共享接口。

**工程软件伴随端**运行在设计人员工作环境中。天河 CAD 端提供图纸读取、对象定位、净化预览、差异叠加、问题跳转和受控写图；Creo 端按项目阶段接入模型结构、参数、BOM 和工程图关联信息，使二维图纸与三维设计数据逐步汇入同一工程对象体系。

### 2.2 Agent 执行环境与共享服务

DeepSeek Harness Agent 是用户任务的运行中枢，负责理解意图、组织步骤、调用天河 CAD、执行几何与规则工具，并在需要时请求人工确认。图纸读取、定位、预览、工作副本修改和 DXF 导出均在安装天河 CAD 的本地环境完成。

FastAPI 提供 Agent 可函数调用的共享接口，包括模型访问、知识与规则查询、项目数据 CRUD、结果沉淀和授权分发。PostgreSQL、Redis、OSS 根据实际协作需要承载共享内容，不构成本地图纸处理的前置流程。系统接口后续可连接综合技术系统、PLM、生产端及 Creo 等工程软件。

## 三、三项共性能力底座

### 3.1 工程图纸数据与操作底座

系统与天河 CAD 深度配合，读取 DWG 中的图层、块、图框、标题栏、明细表、序号、文字、标注、引线、专业符号及基础几何，并进一步识别视图、制造轮廓、孔、中心、接口、尺寸关系和邻接关系。Creo 数据接入后，同步建立模型、装配、零部件、参数、BOM 与工程图之间的关联。

Agent 读取当前图纸并执行具体任务时，逐步形成可复用的工程对象：

- 项目、产品、图纸、图号、版本和审批状态；
- 总装、部件、零件、视图及 CAD 图元；
- 轮廓、孔位、尺寸、接口、材料、数量和参数；
- 明细表、BOM、算单、规则、问题、证据和处理结论。

这些对象保留来源、位置、版本和上下游关系。系统据此提供读取、定位、测量、比较、标记、隐藏、删除、复制、生成、导出和复核等标准操作接口。首期的图纸净化与铁芯校验共用这套能力，后续审图和 CAD 操作可以在同一底座上持续增加。

### 3.2 变压器知识与规则底座

系统建设面向变压器设计全过程的知识与规则中心，纳入双方确认的现行国家及行业标准、项目技术协议、企业设计规定、`TDP`/`0TT` 文件、质量控制计划、标准图、计算规则、典型问题和历史处置经验。知识按产品类型、电压等级、结构型式、部件和项目要求建立适用关系；企业知识及有效版本由沈变按项目计划提供并共同治理。

知识内容按照“产品—部件—图纸—参数—规则—问题—责任人”组织。每条规则记录来源条款、版本、适用产品、启用条件、输入对象、计算口径、公差、例外和审批状态。设计人员查看某张图或某个部件时，系统自动汇集当前适用的规则、关联资料、历史问题和待办事项。

规则知识中心提供以下可见功能：

- **知识检索**：按产品系列、部件、图号、标准号或自然语言查找资料；
- **适用规则**：查看当前项目和图纸应执行的规则清单；
- **关系全景**：查看图纸、零部件、参数、BOM、标准和问题之间的关联；
- **版本追溯**：识别规则的生效、修订、替代和失效状态；
- **影响分析**：规则或参数变更后，定位受影响的产品、图纸和校审任务；
- **规则维护**：由授权专家确认、发布、停用规则并触发回归验证。

### 3.3 大模型与专业智能体底座

系统以 DeepSeek Harness Web 作为智能交互与任务编排中枢，通过插件化专业智能体连接 CAD、几何算法、规则库、知识库、文件服务和业务系统。DeepSeek Flash 承担高频问答、资料归纳和任务路由；复杂问题进入深度推理链路；图纸截图、PDF 和非结构化附件由经批准的视觉模型协同处理。

智能问答综合采用文档检索增强、知识关系增强和工程对象操作增强（RAG/KAG/OAG）。用户提出问题后，智能体可以检索受控资料，沿产品与图纸关系获取上下文，调用专业工具完成测量或校验，再以来源条款、图纸位置和计算证据支撑结论。专项微调安排在真实业务样本、专家答案和验收集形成之后，针对稳定且可量化的领域缺口开展。

系统首期配置四类智能助手：

- **工程知识助手**：回答标准、企业规定、项目要求和历史问题，并展示来源与版本；
- **图纸任务助手**：理解用户意图，组织文件、工具和规则，持续跟踪长流程任务；
- **生产净化助手**：解释净化范围、提示风险、组织人工确认并生成交付说明；
- **铁芯校审助手**：汇总参数、差异和规则依据，辅助形成审查意见及复核记录。

智能体的任务步骤、工具调用、人工确认和结果产物全程留痕。经授权的能力可以通过 API 向其他软件开放，使知识问答、图纸校验和任务编排成为企业可复用的智能服务。

## 四、用户可见的共性功能

### 4.1 智能工作台

- **[新建图纸任务]**：选择任务类型并连接天河 CAD 当前图纸，也可选择本地批处理文件；
- **[智能问答]**：围绕标准、项目、图纸、参数和校审结果连续提问；
- **[项目与图纸全景]**：查看产品结构、图纸版本、关联部件、BOM、规则和问题；
- **[任务中心]**：查看排队、执行、待确认、已完成和失败任务，支持继续处理与重新执行；
- **[问题工作台]**：按严重度、部件、图号和责任人筛选问题，完成确认、退回、豁免和关闭；
- **[报告中心]**：生成审查报告、净化记录、差异清单和可归档结果；
- **[知识与规则]**：检索标准、维护企业规则、查看适用范围和版本影响；
- **[系统管理]**：配置用户角色、项目权限、接口、规则包、模型策略和审计记录。

### 4.2 天河 CAD 伴随端

- **[读取当前图纸]**：提取图号、版本、标题栏、明细表和工程对象；
- **[发起智能任务]**：将当前图纸直接送入净化或校审流程；
- **[定位问题]**：从问题清单跳转到对应视图和图元并高亮显示；
- **[查看差异]**：以叠加、分色和局部放大方式查看预期与实际差异；
- **[确认处理]**：接受建议、调整范围、填写意见或提交上级复核；
- **[生成工作副本]**：将经确认的操作应用于新版本或工作副本，并保留原始图纸；
- **[查看处理记录]**：追溯每次读取、校验、修改、导出和审批动作。

## 五、核心应用一：生产用 DXF 图纸净化

### 5.1 使用场景

设计或生产准备人员选择一张或一批 DWG，系统自动读取图号与版本，识别主生产视图和目标零件，清理图框、剖视/放大视图、尺寸与一般标注、剖切符号、中心线、辅助线及内部技术文字等非生产对象。净化在受控 DWG 工作副本中完成，随后执行制造几何完整性校验并自动导出符合目标生产端约定的 DXF。

### 5.2 主要页面与按钮

1. **[新建净化任务]**：导入单张、多张或压缩包图纸，自动检查文件、图号和版本。
2. **[识别生产对象]**：推荐主视图、零件轮廓和加工区域；复杂图纸可由用户框选确认。
3. **[净化预检]**：按“保留、清理、待确认”展示对象清单和风险提示。
4. **[查看净化预览]**：用分色叠加呈现清理前后差异，支持逐项恢复或调整。
5. **[执行 DWG 净化]**：将已确认规则应用到工作副本，记录每个对象的处理原因。
6. **[制造几何校验]**：复核外轮廓、内轮廓、孔数、孔径、孔中心、连通性、单位、比例和坐标。
7. **[导出生产 DXF]**：按生产端约定输出 DXF 版本、图层、命名和目录结构；安全校验未通过时进入人工复核。
8. **[推送生产端]**：向双方确认的生产系统发送文件并接收处理状态。
9. **[生成净化报告]**：输出文件身份、规则版本、清理统计、几何校验结果、人工确认项和完整操作记录。

### 5.3 用户获得的结果

- 可直接进入目标生产软件验证和编程的 DXF；
- 清理前后可视化对照及对象级处理清单；
- 制造轮廓与孔位完整性校验结果；
- 异常图纸的人工复核任务；
- 可按图号、版本和任务追溯的交付记录。

## 六、核心应用二：铁芯叠片一致性校验

### 6.1 使用场景

校审人员选择铁芯总图、叠片图及参数明细，系统核对文件身份和版本，读取叠片参数并生成预期结构，自动定位图纸中的铁芯与叠片视图，完成坐标、方向和比例对齐。系统逐级比较轮廓、孔位、尺寸、级次关系及相邻叠片错位，并分别核查图面显示尺寸与实际几何测量值。

### 6.2 主要页面与按钮

1. **[新建铁芯校验]**：选择产品、总图、叠片图和参数明细，建立任务关系。
2. **[自动配对与版本检查]**：读取图号、版本和标题栏信息，提示缺失、错配或状态异常。
3. **[读取叠片参数]**：将明细字段映射为可校验参数，显示单位、来源和缺失项。
4. **[定位铁芯区域]**：推荐总图铁芯区域和叠片视图；用户可在 CAD 中调整确认。
5. **[重建预期叠片]**：根据已确认规则生成叠片轮廓、孔位和级次关系，并显示重建预览。
6. **[一键一致性校验]**：执行轮廓、孔位、尺寸、数量、方向、比例和错位检查。
7. **[查看差异叠加]**：将预期图形与实际图形分色叠加，按级次查看差异矩阵。
8. **[定位到 CAD]**：从问题卡片直接跳转到对应图元、参数行和图纸坐标。
9. **[确认/退回/豁免]**：记录工程判断、责任人、处置意见和批准依据。
10. **[生成校审报告]**：形成问题清单、差异证据、规则来源、实测值、期望值和复核结论。
11. **[重新校验]**：设计修改后沿用同一任务上下文复核，并保留前后版本差异。

### 6.3 用户获得的结果

- 由参数明细生成的预期叠片模型和级次矩阵；
- 总图、叠片图与预期结构的差异叠加；
- 轮廓、孔位、尺寸及错位问题的精确定位；
- 每项结论对应的参数、规则、图元和测量证据；
- 支持四级审核流转和归档的结构化校审报告。

## 七、典型智能交互

用户可以在智能工作台或 CAD 伴随端直接提出：

- “这张铁芯图当前适用哪些企业规则和国家标准？”
- “解释第 3 级叠片错位问题，并定位到图中。”
- “这张图为什么暂时不能导出生产 DXF？”
- “列出本批图纸中需要人工确认的视图，并按风险排序。”
- “对修改后的版本重新校验，只汇总新增和已关闭问题。”

智能体返回结论、引用依据和证据卡片，并可在用户确认后继续发起定位、复核、报告或导出任务。用户始终能够看到当前任务使用的图纸版本、规则版本、执行步骤和待确认事项。

## 八、实施与交付路径

### 第一阶段：业务基线与联合定义

双方确认试点产品范围、图号版本规则、参数明细口径、净化对象清单、制造几何保护清单、目标 DXF 规范、校验公差、异常处置流程和验收样本。同步明确企业知识提供与规则发布责任。

### 第二阶段：平台底座与 DXF 净化应用

交付 C/S 基础平台、Web 智能工作台、天河 CAD 伴随端、图纸对象模型、知识规则中心和首批专业智能体；完成单图、批量、预览、人工确认、DWG 工作副本净化、几何安全校验、DXF 导出和任务报告。

### 第三阶段：铁芯叠片一致性校验应用

交付参数明细映射、叠片结构重建、视图定位、图形对齐、矢量校验、差异叠加、问题处置和校审报告；以双方冻结的测试集与人工校审结果开展对比验收。

### 第四阶段：生产集成与能力扩展

完成两个生产端的文件与状态接口，接入具备条件的综合技术系统或 PLM 数据；逐步引入 Creo 模型结构、参数、BOM 和工程图关系。基于同一底座扩展尺寸完整性、BOM 一致性、跨图接口、版本差异、技术要求和受控 CAD 操作等能力。

- 标准与企业知识库、规则库、版本治理和关系全景；
- 生产用 DXF 图纸净化应用及生产交付记录；
- 铁芯叠片一致性校验应用及结构化校审报告；
- 用户权限、任务审计、运行监控、接口日志和管理工具；
- 项目配置、测试集、验收报告、用户手册和运维文档。

## 十、验收关注点与协作条件

生产用 DXF 图纸净化以受保护制造几何完整、目标生产软件可读取与可编程、批量任务可追溯为主要验收方向。铁芯叠片一致性校验以文件配对准确、参数重建正确、差异定位清晰、证据完整及专家盲测结果为主要验收方向。具体覆盖率、准确率、公差和性能指标由双方依据冻结样本共同确定。

项目启动时，沈变需协助提供经脱敏授权的典型与异常样本、现行规则及历史版本、参数明细与重建规则、制造几何清单、生产 DXF 接口约定、专家答案和验收数据；同时确认天河 CAD 的批处理部署及授权方式、Creo/PLM 可开放的数据范围、内网服务器和模型运行环境。上述信息将直接形成项目配置和验收基线。

系统按首期约 10 人并发场景规划任务调度与运行监控，并根据真实图纸大小、批量峰值和生产端响应情况完成容量校准。原始设计文件全程保留，自动处理作用于工作副本；所有修改、导出、规则变更和人工判断均可追溯。

## 十一、预期成效

两个首期应用将形成从“图纸进入系统”到“结果进入生产或校审流程”的完整闭环。设计人员能够在熟悉的天河 CAD 环境中完成定位和确认，管理人员能够通过 Web 工作台掌握任务、问题、规则和版本，企业标准与经验能够持续沉淀为可执行、可治理的工程知识。

随着 Creo 和业务系统数据逐步接入，系统将持续积累产品结构、图纸关系、设计参数、校审证据和处置经验，形成面向变压器研发全流程的工程智能基础设施，为后续多专业审图、设计复用、质量追溯和智能设计辅助提供统一支撑。
