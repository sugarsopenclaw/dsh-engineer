### 3. 序号气泡 ↔ 明细行

来源：命名字典 `PC_BOMXHRELATEDIC`，键为 `序号#气泡Handle十进制`。24 条全部对上。


| 字段           | 本图例子              | 说明                               |
| ------------ | ----------------- | -------------------------------- |
| seq          | 1                 | 序号                               |
| xuhao_handle | 1F6A              | 图面气泡的 DWG Handle                 |
| bom_handle   | 4575              | 明细表那一行的 Handle                   |
| bom_code     | 8TBT.055.T00001.1 | 该行代号                             |
| bom_name     | 箱底5336×…          | 该行名称                             |
| bom_qty      | 1                 | 该行数量                             |
| dict_key     | 1#8042            | 字典原始键（8042 即 handle `1F6A` 的十进制） |


点气泡 `1F6A` 就能定位到明细第 1 行，不需要认气泡里的字。

## 二、CAD 符号表（规范检查用）



### 5. 图层（36）

字段：name、handle、off、frozen、locked、color、linetype。


| 字段       | 本图例子                  | 说明   |
| -------- | --------------------- | ---- |
| name     | 7标注层 / 4油箱-1轮廓线 / 图框层 | 机械分层 |
| off      | 消隐层 = 是，其余否           | 关闭的层 |
| color    | 7标注层 = cyan           | 颜色   |
| linetype | 3中心线层 = CENTER        | 线型   |


本图 frozen、locked 全否。

### 6. 线型（9）

字段：name、handle、ascii_description。

例子：Continuous、DASHED、CENTER、DIVIDE、PHANTOM、CENTERX2。

### 7. 文字样式（6）

字段：name、handle、font_file、big_font_file、text_size。


| name                                   | 本图例子                  | 说明                  |
| -------------------------------------- | --------------------- | ------------------- |
| Standard                               | thenor.shx + hzfs.shx | 西文+中文大字体            |
| TH_GBDIM / PC_TEXTSTYLE / THXuHaoStyle | 字体文件名为空               | 本机缺天河字库时路径抽空，文字内容仍在 |




### 8. 标注样式（5）

字段：**只有** name、handle。

例子：TH_GBDIM、TH_GBDIM1、ISO-25、STANDARD。  
没有文字高、箭头、精度等 DIM 参数。

### 9. 布局（3）

字段：name、handle、tab_order、model_type、block_handle。


| name      | 本图       | 说明     |
| --------- | -------- | ------ |
| Model     | 1487 个实体 | 图在模型空间 |
| 布局1 / 布局2 | 0 个实体    | 图纸空间空  |




### 10. 块清单（155：42 有名 + 113 匿名）

字段：name、handle、owner_scope、是否布局/匿名/xref、属性定义、实体数、原点。


| 名称               | 本图例子       | 说明     |
| ---------------- | ---------- | ------ |
| PC_TITLE_BLOCK 等 | 定义里 99 个实体 | 标题栏块定义 |
| MYX              | MYX13381 等 | 零件块    |
| Dnn              | 113 个      | 标注用匿名块 |
| xref             | 无          | 本图没有外参 |




### 11. XData 应用名（RegApp 38）

字段：name、handle。只是「图里注册过哪些扩展数据名」。

天河相关例子：TH_XUHAO、TH_BOMRecorder、TH_XDATA_CODE、TH_SUPERPART。  
注册了不等于每条图元都有值；序号气泡上就没有这些 XData。

## 三、图元库（定位、几何、规范）



### 12. 每条图元的公共字段

来源：`entities.jsonl`，3570 条。


| 字段            | 本图例子                      | 说明              |
| ------------- | ------------------------- | --------------- |
| handle        | 15D5、1F6A、438F            | 定位主键，两边 CAD 能对上 |
| runtime_class | AcDbLine / TH_XuHaoEntity | 天河里专业对象已是真类名    |
| layer         | 7标注层                      |                 |
| geometry      | 直线起终点、圆半径、块插入点…           | 按类型不同           |
| text          | 图面上的字                     | 无线则无此键          |
| attributes    | 见标题栏/明细                   | 仅块参照            |
| xdata         | 明细行上 TH_XUHAO=`"1"`       | 有则带上            |
| decode_status | 全部 full                   | 无 proxy         |


类型数量最多：Line 1865、Solid 353、Point 338、Arc 168。专业类：序号气泡 24、引出 24、基准 3、箭头线 2。

## 四、有表但读不出业务字段

这些对象在，handle 和类名都有，**没有**件号/粗糙度值/基准字母这类列。


| 对象                   | 能举的例子                    | 缺什么               |
| -------------------- | ------------------------ | ----------------- |
| TH_XuHaoEntity（24）   | handle `1F6A`，层 7标注层     | 气泡内部参数；序号靠第 3 节关联 |
| TH_DimLeaderUA（24）   | handle `17FD`            | 引出专业参数            |
| TH_ParaBasePntUA（3）  | 仅 handle、类名              | 基准参数              |
| TH_CVArrowLine（2）    | 仅 handle、类名              | 箭头参数              |
| TH_BOMRecorder 等字典记录 | PC_BOM_DIC 里 24 个 handle | 记录体               |


---



## 五、本图根本没有的数据


| 类型             | 说明         |
| -------------- | ---------- |
| 算单、项目树、ERP 物料账 | 不在这张 DWG 里 |
| 图纸 PNG/PDF     | 没做出图       |
| 外参 xref        | 块表里没有      |


---

一句话对照：机械三张表（标题栏、明细、序号关联）字段是齐的；CAD 符号表是名称级齐的；图元是条数齐的；天河符号内部参数没有列。
